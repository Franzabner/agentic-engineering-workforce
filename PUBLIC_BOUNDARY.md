# Public Boundary

This public scaffold contains synthetic public-safe agentic engineering workflow documentation only.

Held out:

- active agent workforce claims, autonomous production agent claims, production execution claims, released software claims, and proof-completion claims;
- internal specialist prompts, private agent memory, sealed agent memory, private runtime details, internal coordination layer internals, and production execution logs;
- live tool tokens, credentials, private repo paths, customer data, Foundation-private data, and internal company product names.

Any future release, routing, metadata expansion, or status expansion requires human review, validator rerun, clean status, and separate approved patches.
