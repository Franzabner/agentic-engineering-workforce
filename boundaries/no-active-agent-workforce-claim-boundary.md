# No Active Agent Workforce Claim Boundary

Status: scaffolded
Publication state: public scaffold
Release state: not released

## Purpose

This boundary prevents public agentic engineering documents from implying active autonomous agents, production execution, or AI authority over architecture.

## Allowed Framing

Allowed public framing:

- AI-assisted engineering review patterns;
- synthetic agent-role vocabulary;
- task lifecycle templates;
- human approval boundaries;
- refusal and escalation rules.

## Not Allowed

Do not claim an active agent workforce, autonomous production agents, released software, live tool execution, production workflow operation, deployment, customer delivery, benchmark results, proof completion, or architecture authority held by an AI system.

Do not include private prompts, private agent memory, sealed agent memory, live tool tokens, credentials, private repo paths, private runtime details, production execution logs, or customer data.

## Review Rule

If a public reader could reasonably infer active production agents, rewrite the artifact before publication.
